# Planet textures

Download these **2K** files from **Solar System Scope**: https://www.solarsystemscope.com/textures/
(license: CC BY 4.0, credit "Planet textures: Solar System Scope (CC BY 4.0)").

Put them in this folder with exactly these names:

| File | Used for |
|---|---|
| `2k_sun.jpg` | Sun |
| `2k_mercury.jpg` | Mercury |
| `2k_venus_surface.jpg` | Venus |
| `2k_earth_daymap.jpg` | Earth |
| `2k_moon.jpg` | Moon |
| `2k_mars.jpg` | Mars |
| `2k_jupiter.jpg` | Jupiter |
| `2k_saturn.jpg` | Saturn |
| `2k_saturn_ring_alpha.png` | Saturn's ring (has transparency) |
| `2k_uranus.jpg` | Uranus |
| `2k_neptune.jpg` | Neptune |
| `2k_stars_milky_way.jpg` | Star background (skybox) |

If a file is missing, the app shows that body in a plain color and writes the missing
file name to `SolarSystem.log`.
